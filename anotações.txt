sudo /opt/nexus_sanitize_users.sh --csv /opt/usuarios.csv --apply

nexus-users-apply

Ao processar action=create em modo apply:
- o script pede a senha temporaria de forma oculta;
- pede a confirmacao da senha;
- nao registra a senha no CSV, JSON ou historico;
- obriga o usuario a trocar a senha no primeiro login.

DASHBOARD WEB (nexus_dashboard/):
- mesmo fluxo acima, porem via interface grafica (botoes) em vez de terminal;
- usa Ansible + Ansible Vault no lugar do SSH manual, sem pedir senha por servidor;
- IA local (sem API externa) resume cada usuario: permissoes, dias bloqueado,
  quem/quando criou, documentos vinculados, comandos executados (best-effort);
- contas bloqueadas sao removidas automaticamente apos 90 dias.

# ============================================================
# MODELO DE PREENCHIMENTO - NEXUS USER SANITIZER
# ============================================================
#
# username:
#   Nome do usuário Linux.
#   Exemplo: joao.silva
#
# action:
#   create = cria o usuário
#   add    = cria o usuário
#   lock   = bloqueia a conta
#   remove = remove o usuário
#   purge  = remove o usuário e apaga a home
#
# home:
#   create: yes cria home, no não cria home
#   remove: yes apaga a home, no mantém a home
#
# reason:
#   Motivo da ação. Não usar vírgula.
#
# ticket:
#   Número do chamado interno.
#
# groups:
#   Grupos adicionais separados por ponto e vírgula.
#   Exemplo: sudo;docker
#
# shell:
#   Shell do usuário.
#   Exemplo: /bin/bash
#
# EXEMPLO:
# username,action,home,reason,ticket,groups,shell
# rebeca,create,yes,admissao,CHG1001,sudo,/bin/bash
# usuario_teste,remove,yes,desligamento,CHG0001,,
#
# ============================================================
